# LokSetu overview interaction redesign prompt

Redesign the LokSetu executive Overview as a calm, high-trust decision cockpit for elected representatives and administrators. Preserve the existing information architecture, live data, navigation, and accessibility semantics. Make the dashboard feel interactive without adding decorative complexity.

The user should be able to switch between AI priority, delivery risk, and citizen impact lenses; select a project from the priority list, map, progress tracker, or budget chart; and see every selection synchronize into one clear decision-focus summary. Turn static KPI cards and alerts into obvious drill-down paths. Keep the visual language civic, professional, data-dense, responsive, keyboard accessible, and readable on desktop and mobile. Use restrained blue, navy, amber, and green states, strong focus rings, concise microcopy, and motion only as feedback.

Success means a first-time user can answer three questions in seconds: what needs attention, why it matters, and where to act next.
